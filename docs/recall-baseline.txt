Interpretation
--------------
1. Sanitizer fix unlocks every multi-term query — implicit AND was the
   pure blocker. No embeddings needed for these.

2. Mono-term zero-hits (q12 крашнулся, q17 починили, q18 сломалась,
   q19 postmortem) remain unsolved. The corpus DOES contain the related
   incident notes (see q5 hit 01KMS8PR1K2ENKARMP1JWQ60QM — incident
   post-mortem from March 27, 2026). FTS5 with `unicode61` tokenizer
   has no morphology, no stemming, no synonyms. These four are the
   acceptance criteria for Step 2.

3. The `unicode61 remove_diacritics 2` tokenizer behaviour:
   - "сломал" stems nothing → "сломалась" is invisible
   - "крашнулся" / "крашнул" / "крашится" — all separate tokens
   - "postmortem" vs "post-mortem" — different tokens (hyphen splits)
   - "лёг" vs "лег" — diacritic-normalised → match (q14 → 1 hit)

Step 2 success metric
---------------------
After hybrid RRF (k=60), expected outcome:
- q12, q17, q18, q19 → ≥1 hit each (concept-match via bge-m3)
- q1..q11 → top-3 stability ≥80% (no regression on FTS5-strong queries)
- New query set (10 morphology variants of q12-q20 stems) → ≥70% hit rate
